HTM2TXT by Mihailo Despotovic, February 1997

A DOS command-line tool that turns a web page into plain text by leaving out everything between < and >. Paste HTML, open a file, or drop one on the page. Its messages were already in English in 1997.

HTML

Text

Like the original, it keeps everything else exactly as it was: line breaks and indentation, entities such as &amp; undecoded, and the contents of scripts and style sheets. One real bug is fixed: the program read each byte into a char and compared it with EOF, and since Borland C's char is signed, a byte 255 (ÿ in Latin-1, a no-break space in the DOS code page for Serbian) looked like the end of the file, and the conversion quietly stopped there. Reading the file in DOS text mode also stopped at the first Ctrl-Z. The checkbox brings both back.
