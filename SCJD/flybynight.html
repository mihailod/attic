Fly by Night Airline Booking by Mihailo Despotovic, January 2001

My Sun Certified Java Developer assignment. Two clients share one flight database, as if connected to the same server. Search for flights, click one, enter the number of seats and click Book. Each booking locks the flight’s record, rereads it, updates the seats and unlocks it. Turn on slow booking, book a flight in one client and quickly book the same flight in the other: the second client waits for the lock, then sees the seats the first one left. A client’s table updates when it searches or books.
