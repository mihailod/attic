    Client Application

    The purpose of the client application is to provide easy user interface for booking the seats on desired flights. The client application has ability to connect both to local and to remote database.

    In order to start the client application you have to do the following:

  • change your working directory to the application root directory (the one you unpacked distribution .jar file into)
  • issue the following command:
    • java -Djava.security.policy=client.policy suncertify.client.Client
    The user interface is very simple, the menu consists of three menu items:

  • File (Connect Remote, Connect Local, Disconnect, Exit)
  • Look&Feel (dynamic list of available look and feels)
  • Help (Quick Help, About)


    • There are two dropdown list boxes:
  • Departing From
  • Arriving To


    • And two buttons:
  • Search
  • Book


    • There is also combination of drop down list box and input field where you can type the number of seats you want to book on the particular flight or you can select 1, 2, 3 or 4 seats from the drop down list.

    The suggested usage of the application is as follows:

    1. Connect to the database using File/Connect menu item
    2. Use Origin/Destination boxes and Search button to find desired flight(s)
    3. Select the desired fligh
    4. Select or enter the number of seats
    5. Use Book button to book the seats
    6. Repeat steps 2-5
    6. When you are done, use File/Disconnect menu item to disconnect from the database

    Database Server

    The purpose of database server is to provide remote access to the Fly by Night data. Database server always provides access to the specific database file.

    Usage of database server is as follows:

  • change your working directory to the application root directory (the one you unpacked distribution .jar file into)
  • issue the following command:
    • java -Djava.security.policy=server.policy suncertify.server.Server
[<serverName> <serverDNSname> <port> <java.rmi.server.codebase>]
    If invoked with no arguments, the defaults are going to be used:
  • Server Name: fbnServer
  • Server URL: localhost
  • Server Port: 5015
  • RMI Codebase: http://localhost/

    Data Conversion Tool

    The purpose of the conversion tool is to convert legacy data files (ASCII text files) into binary files readable by the Fly by Night Database Engine.

    Usage of the conversion tool is simple:

  • change your working directory to the application root directory (the one you unpacked distribution .jar file into)
  • Start the module witht the following command: 
    java suncertify.dataconverter.Converter <legacy file> <DB file>
    • The conversion tool will display it's progress. If DB file already exists, you will have chance to choose either to append new data or to create a brand new file (the later option will erase old data in the file). If anything goes wrong with the particular information in legacy file, that information is going to be skipped and you will be informed about the problematic line number in the legacy file.

    Once the conversion is over, you can start using the converted file by connecting to it from the Client Application.

    Example: 
    >java suncertify.dataconverter.Converter testascii.txt a.db
