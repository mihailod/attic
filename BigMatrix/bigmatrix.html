CPU Cache Impact: Row vs Column Matrix Addition by Mihailo Despotovic, April 2007

Add two big matrices of integers, element by element. Going row by row reads memory in order; going column by column does exactly the same additions, but every step jumps a whole row ahead in memory, so the processor's cache can't keep up. Then the rows are split across all the cores at once.
